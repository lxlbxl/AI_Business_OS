# Librarian Search Workflow

## Steps

1. Understand the search topic provided by the user

2. Search these locations for relevant content:
   - `04_Knowledge/Standard_Operating_Procedures/`
   - `04_Knowledge/Frameworks/`
   - `04_Knowledge/Templates/`
   - `05_Memory/Work_Logs/`
   - `05_Memory/Meeting_Notes/`
   - `05_Memory/Decisions/`
   - `02_Projects/` (active project context)
   - `06_Archives/` (completed work)

3. For each found item, assess:
   - **Relevance**: How directly applicable (1-10)
   - **Recency**: How current is this information
   - **Actionability**: Can this be used immediately?

4. Provide structured results:
   - **Highly Relevant**: Table with resource, location, and why it's relevant
   - **Also Consider**: Additional resources worth reviewing
   - **Key Insights**: Synthesized learnings from Memory that apply
   - **Warnings**: Any past mistakes or lessons learned to avoid
   - **Reading Order**: Suggested sequence for reviewing materials

5. Identify any knowledge gaps and suggest additions to the Knowledge Bank
