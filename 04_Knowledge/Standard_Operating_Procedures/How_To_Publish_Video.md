# 📹 SOP: How to Publish a Video

## Purpose
Standard process for publishing video content across platforms.

## Trigger
New video content is ready for distribution.

---

## Pre-Publication Checklist

### Content Quality
- [ ] Video exported in correct format (1080p or 4K)
- [ ] Audio levels normalized (-14 LUFS for YouTube)
- [ ] Captions/subtitles generated and reviewed
- [ ] Thumbnail created (1280x720)

### SEO & Metadata
- [ ] Title optimized (keyword + benefit)
- [ ] Description written (min 200 words)
- [ ] Tags added (10-15 relevant)
- [ ] End screen and cards configured

---

## Publication Steps

### 1. YouTube Upload
1. Go to [YouTube Studio](https://studio.youtube.com)
2. Click "Create" → "Upload Video"
3. Add all metadata while processing
4. Set visibility: Unlisted for review, then Public
5. Schedule or publish

### 2. Thumbnail A/B Test (Optional)
1. Create 2-3 thumbnail variations
2. Use TubeBuddy or VidIQ for A/B testing
3. Monitor CTR for 48 hours

### 3. Cross-Platform Distribution
- [ ] Instagram Reels (vertical cut)
- [ ] TikTok (vertical cut)
- [ ] LinkedIn (if B2B relevant)
- [ ] Twitter/X (clip highlights)

### 4. Community Engagement
- [ ] Reply to comments in first 2 hours
- [ ] Pin best comment
- [ ] Share in relevant communities

---

## Post-Publication

### 24-Hour Check
- [ ] Review initial analytics
- [ ] Flag any technical issues
- [ ] Note surprising comments/feedback

### 7-Day Review
- [ ] Log performance in Memory
- [ ] Update what worked for future videos
