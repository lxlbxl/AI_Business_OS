# Weekly Review Workflow

## Steps

1. Read ALL daily log entries from the past 7 days in `05_Memory/Work_Logs/[current-month].md`

2. Aggregate data:
   - Total tasks completed
   - Projects touched
   - Blockers encountered
   - Learnings accumulated

3. Calculate metrics:
   - Strategic Alignment %: (Aligned tasks / Total tasks) × 100
   - Bottleneck Focus %: (Bottleneck tasks / Total tasks) × 100
   - Completion Rate: (Completed / Planned) × 100

4. Read `01_Strategy/Current_Bottleneck.md` and assess:
   - Has it been resolved? (Yes/Partially/No)
   - If Yes: What's the NEW bottleneck?
   - If No: What's blocking resolution?

5. Generate weekly report: `05_Memory/Work_Logs/Weekly_Reviews/[YYYY]-W[WW].md` including:
   - Key metrics with status indicators
   - Wins and misses
   - Key learnings
   - Bottleneck status and recommendation
   - Next week's top 3 priorities
   - Things to stop and start doing

6. If bottleneck has shifted, update `01_Strategy/Current_Bottleneck.md`

7. Report summary:
   - One sentence: How did the week go?
   - Biggest win
   - Biggest concern
   - ONE change for next week
