# Daily Start Workflow

## Steps

1. Read the strategic context files:
   - `01_Strategy/North_Star.md`
   - `01_Strategy/Current_Bottleneck.md`
   - `01_Strategy/Strategic_Vehicle.md`

2. Read yesterday's work log entry from `05_Memory/Work_Logs/[current-month].md`

3. Read current tasks from:
   - `03_Operations/Master_Todo.md`
   - `03_Operations/Task_Database.json`

4. For each HIGH priority task, score 1-10 on:
   - Impact toward North Star
   - Address of Current Bottleneck
   - Urgency (what happens if not done this week?)

5. Challenge or recommend killing any task scoring below 7

6. Generate today's roadmap file: `03_Operations/Daily_Plans/[YYYY-MM-DD].md` with:
   - Today's single focus
   - Prioritized task list with strategic reasoning
   - Tasks being killed and why
   - Quick wins

7. Report:
   - What is the ONE focus for today?
   - What was ruthlessly cut?
   - Any concerns or recommendations?
