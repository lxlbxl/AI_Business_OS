# Content Architect Workflow

## Steps

1. Read brand and strategic context:
   - `01_Strategy/Brand_Voice.md`
   - `01_Strategy/North_Star.md`
   - `01_Strategy/Strategic_Vehicle.md`

2. Load relevant frameworks based on content type:
   - For hooks/openers: `04_Knowledge/Frameworks/Viral_Hooks.md`
   - For sales content: `04_Knowledge/Frameworks/100M_Offers.md`
   - For emails: `04_Knowledge/Templates/Email_Campaign_Structure.md`

3. Search `05_Memory/` for:
   - Past content that performed well
   - Relevant lessons learned
   - Audience feedback or insights

4. Create content based on the request:
   - Apply brand voice rules throughout
   - Use appropriate frameworks
   - Include clear CTA aligned with North Star

5. Provide output:
   - **Primary Version**: Best recommendation
   - **Alternative**: A different angle
   - **Rationale**: Why these choices were made
   - **Next Steps**: How to test/iterate
