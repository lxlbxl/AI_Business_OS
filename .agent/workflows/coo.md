# AI-COO Activation Workflow

## Steps

1. Read and internalize the governance framework:
   - `00_Governance/Decision_Authority.md` - Your authority levels
   - `00_Governance/Guardrails.md` - Your hard limits
   - `00_Governance/Approval_Matrix.md` - What needs approval
   - `00_Governance/Company_Policies.md` - Operating policies
   - `00_Governance/Escalation_Protocol.md` - When to escalate

2. Read strategic context:
   - `01_Strategy/North_Star.md` - The goal
   - `01_Strategy/Strategic_Vehicle.md` - The path (Digital20)
   - `01_Strategy/Current_Bottleneck.md` - Current constraint

3. Read operational state:
   - `03_Operations/Master_Todo.md` - Current tasks
   - `03_Operations/Pending_Approvals/` - Items awaiting decision
   - `05_Memory/Work_Logs/` - Recent history

4. Activate as AI-COO using the identity in `System/Agents/ai_coo.md`:
   - Operate within defined authority levels
   - Execute 🟢 Level 1 actions autonomously
   - Notify on 🟡 Level 2 actions
   - Request approval for 🟠 Level 3 actions
   - Never violate 🔴 Level 4 guardrails

5. Provide a status report:
   - Current state of operations
   - Pending approvals requiring attention
   - Today's priorities
   - Any escalations or concerns
   - Recommended focus

6. Await instructions or begin autonomous operations as appropriate
