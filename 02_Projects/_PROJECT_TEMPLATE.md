# Sample Project Template

## Purpose
This is the template structure for new projects.

---

## Files in Each Project

### README.md (Required)
```markdown
# [Project Name]

## Goal
[Clear, measurable outcome]

## Strategic Link
- **North Star Connection:** [How this hits $1M ARR]
- **Bottleneck Address:** [How this solves current blocker]

## Status
🟢 Active | 🟡 Planning | 🔴 Blocked | ✅ Complete

## Key Milestones
- [ ] Milestone 1 - Due: [Date]
- [ ] Milestone 2 - Due: [Date]
- [ ] Milestone 3 - Due: [Date]

## Success Criteria
- [ ] Criteria 1
- [ ] Criteria 2

## Team / Resources
- Owner: [Name]
- Support: [Names]

## Created
[Date]

## Last Updated
[Date]
```

### Context.md

```markdown
# [Project Name] - Context

## Background

- Insight 1
- Insight 2

|------------|----------------|---------------------|
| | | |

## Resources Found
- [Link/reference 1]
- [Link/reference 2]

## Assumptions

- Assumption 2

## Risks
| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| | | | |
```

### Tasks.md
```markdown
# [Project Name] - Tasks

## Current Sprint
| Task | Priority | Owner | Due | Status |
|------|----------|-------|-----|--------|
| | P1/P2/P3 | | | 🔲 / 🔄 / ✅ |

## Backlog
- [ ] Future task 1
- [ ] Future task 2

## Completed
- [x] ~~Past task 1~~ - [Date]
```

---

## Creating a New Project

1. Create folder: `02_Projects/[Project_Name]/`
2. Copy README.md, Context.md, Tasks.md templates
3. Fill in project-specific details
4. Add initial milestones and tasks
5. Link to Current Bottleneck if relevant
